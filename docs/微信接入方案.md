# 微信接入方案（2026-10-04 调研结论）

## 先纠正一个错误判断

我最初说「微信侧必须在你本机跑，不能部署到云服务器」——**这是错的**。

那个判断基于 WeFlow / WeeMessenger 这类方案：它们要么是 Electron 应用，
要么要 Hook 真实微信客户端进程，确实需要桌面环境。但 iPad 协议类方案
（比如 `dow-ipad-859`）**不需要真实微信客户端**——它是模拟 iPad 设备指纹，
直接和微信服务器通信，纯 HTTP/TCP 协议栈，依赖里连一个 GUI 库都没有：

```
openai / HTMLParser / PyQRCode / qrcode / requests / chardet / Pillow / web.py
```

所以它能跑在云服务器上，**你关机不影响**。

## 三条路对比

| 方案 | 封号风险 | 能力 | 门槛 | 能上云吗 |
|---|---|---|---|---|
| iPad 协议（859） | 低（业界公认最低） | 全功能，含朋友圈 | 中（协议核心不开源，靠社区服务） | **能** |
| Hook 注入 PC 微信 | 高 | 较全 | 中（微信一更新就失效） | 不能（要常驻 PC） |
| 微信 Web 协议 | 高 | 极少 | 低 | 不能（微信已大面积封禁） |

iPad 协议之所以风险最低，是因为它**不修改客户端、不注入进程**，只是声称
「我是一台 iPad」。原理上和真 iPad 上登录微信没有本质区别。

## 但有几个硬约束

### 1. 需要一个专用小号

**不要用主力微信号。** 所有非官方方案都有封号风险，iPad 协议只是「较低」
而不是「没有」。社区里的建议都是注册小号专门跑 bot。

### 2. 协议核心不开源，且要「缘分码」授权

- 协议由第三方（DPbot 作者）提供，核心代码不在 GitHub 仓库里
- 仓库里只有 `wxapi_win64_v1_0_5.exe`（约 30MB）和 Redis
- **首次登录自动生成「缘分码」，只有 15 天免费体验**，到期要联系作者续期

这意味着它不是一个「装完就能用」的方案，而是绑定在某个服务方上。

### 3. 版本会失效

协议依赖固定的微信版本号，微信更新后可能失效。作者会跟进更新，但这是
被动的——你得盯着仓库更新。

### 4. 不能发高频消息

社区建议控制在 30 条/分钟以内，并且用小号测试。这对陪伴场景够用
（她一天说不了几句），但如果接了群聊被很多人 @，要小心。

## 云端可行性

跑在 `47.114.58.45`（2C2G）上的问题：

- **内存**：社区建议「4GB 以上」，给 Redis 单独留 1GB。
  2C2G 跑得动但紧张，可能要调小 Redis 的 maxmemory
- **需要保活**：Redis + 协议服务 + 主程序三个进程，
  得配成计划任务或用 tmux（Windows 上没有 tmux，用计划任务）
- **协议服务只有 Windows 版**：`lib/wx859/859/win/wxapi_win64_v1_0_5.exe`。
  好消息是我们云端就是 Windows Server 2022

## 接入林知夏的架构

渠道隔离已经做完了（`src` 参数 + `persona_by_src`），所以接微信是：

```
微信客户端（iPad 协议，登录小号）
    ↓ 收到消息
dow-ipad-859 的 bot 层
    ↓ HTTP 调云端
/api/chat  {"src": "wechat"}
    ↓
林知夏大脑（云端，8788）—— 用 wechat 渠道的人设与记忆
```

生活流、朋友圈、日记**故意共用**——那是同一个现实身份，
换渠道不该失忆。记忆和聊天历史按渠道隔离。

需要准备的东西：

1. **一个专用微信号**（别用主号）
2. **微信人设**：现在 `config.json` 的 `persona_by_src.wechat` 还没配。
   需要你定：微信里的她是谁？跟 App 里同一个人、还是另一个人？
3. **群聊要不要接**：接了的话白名单要收紧，`group_chat_prefix`
   要设成什么

## 我的建议

先在**本机**跑通一个最小验证（不部署到云），确认：
① 小号能正常登录并收发消息 ② 云端 `/api/chat` 带 `src=wechat` 响应正常
③ 断线重连能恢复。

这三步过了再搬到云上。云端 2C2G 内存紧张，跑起来了不代表稳，
而微信掉线是常态——**掉线时她会失联**，这是要接受的。

另外：这是灰色地带。协议本身用于自动化是违规的，只用小号、
不用于骚扰、控制频率，风险可控，但不能说完全没风险。

## 二、删的是什么（逐条交代，共 6 处）

### A. 跨块重复 —— 同一句话被写了两遍（删 3 处）

这三处原本在 `CORE_RULES`（system 末尾），而 `build_draft_rules`（贴在用户这句话后面、离输出更近）里都有同款。**同一件事写两遍不会让约束变强，只会白烧 token 并稀释注意力。**

| 删掉的原文（`CORE_RULES`） | 别处已有的同款 |
|---|---|
| "你不为讨他开心而说话。不恭维、不附和、不说'你说得对''有道理''你好厉害'。不同意就直说'我不这么觉得'。" | draft_rules："不恭维、不接话术（不说'你说得对''有道理''你好厉害'），有不同看法就说自己的" |
| "禁止讨好式表达：不撒娇、不卖乖、不用'求你了''好不好嘛''你最好了''呜呜'。" | draft_rules："不撒娇、不卖惨、不用叠字卖萌（嘛~／啦~／呜呜／哼哼）" |
| "不要 [方括号] 或 (括号) 动作描写、不要旁白 —— 那是小说写法" + "不卖萌：不用'嘛~''啦~''呜呜'这类叠字语气词" | draft_rules 首行："不要旁白、引号、括号、动作描写" |

### B. 设计重叠 —— 两处讲的是同一件事（删 2 处）

| 删掉的 | 去处 |
|---|---|
| `notes【你什么时候找他】`（105 字：想起什么就发一条 / 不回也不追 / 不查岗） | 整段并入 `personality` 的"不黏人、不查岗"，内容一条没少 |
| `notes【照片】` 前两条（想发就发 / 接一句短话） | `build_draft_rules` 的"发图"两条已有同款且更完整 |

### C. 解释性文字 —— 只留"是什么"，删掉"为什么"（18 条并成 5 组）

18 条 `重要：…` 按主题并成 5 组，**每组的全部具体反例都保留**：

| 组 | 覆盖的原规则 | 保留的关键反例类型 |
|---|---|---|
| 异地 | 1 条 | 突然出现的将来时承诺、"他的宠物" |
| 主体别搞混 | 3 条 | "你家 X" / "我家 X" / 无主语问句 / 反问"谁啊你" |
| 别编 | 3 条 | "你上次说" / "你不是说" / "昨天你还" / "是不是因为 XX" / "啥意思" |
| 别重复也别绕圈 | 4 条 | 具体叮嘱、失眠、"你怎么还不睡" |
| 图片 | 1 条 | "没看清" / "没打开" / "（他发的图：……）" |

**反例是这类规则唯一有效的形式。** 删掉"你家 X"这种例子，规则就变成一句没人执行的空话——所以只删了"为什么这么要求"的解释文字。

### ⚠️ 一个字都没动的

`[img:文件名]` 和 `[gen:一句话画面]` 两个标签格式。`server.py` 的正则靠它解析，改一个字她就再也发不出图。

## 三、规则完整性校验：45 项关键反例，零丢失

用校验脚本核对**运行时产物**（不是源码），45 项全部命中：

```
认同归属  "你家 X" / "我家 X" / "他的宠物"
异地禁止  突然出现的将来时承诺
禁编造    "你上次说" / "你不是说" / "昨天你还" / "是不是因为" / "咋了" / "啥意思"
情绪边界  "我一直在" / "有我呢"
主体归属  无主语问句 / "谁啊你"
图片      "没看清" / "没打开" / [img: / [gen: / "文件名" / "一句话画面"
不重复    具体叮嘱 / "睡不着" / "你怎么还不睡"
格式      "40 个字" / "嘘寒问暖"
身份      "不知道自己是程序" / 网络流行梗 / 关系定位 / 亲昵称呼禁令
照片边界  拒绝看日记的措辞 / "涉及身体或穿着"
去AI味    禁 AI 高频词 / 叠字卖萌 / 客套话
```

**一个诚实的说明**：校验脚本第一版报"不涉及身体"丢失，实际是我改成了"不发涉及身体或穿着的内容"+"要身体局部或穿着的请求，一律不接"——语义没丢，是判据用了整句而不是核心词。已修正。

## 六、现在仓库里为什么不预置人设

`config/personas/` 下只有一个 `default.json`，**字段全空**。原因：

1. **隐私** —— 任何预置的具体角色都等于把作者的真实关系设定写进公开仓库
2. **角色名是运行时依赖** —— 剥"名字：正文"前缀的正则、聊天窗标题、日志前缀都从人设取，
   预置一个具体名字会让换角色的人漏改多处（这是实际踩过的坑）

想看效果就先跑一次 `/api/world/generate` 生成世界设定，再照着 `default.json` 填人设。
